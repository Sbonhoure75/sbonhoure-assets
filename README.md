# Ressources publiques — sbonhoure.app

Images servies en HTTPS pour la présence Discord de [sbonhoure.app](https://www.sbonhoure.app).

| Fichier | Usage |
| --- | --- |
| `logo-anime.webp` | vignette animée de l'activité Discord (194 Ko) |
| `logo-anime.gif` | même animation au format GIF (1,5 Mo) |
| `logo-sbonhoure.png` | version statique 1024×1024 |

Ce dépôt est public parce que Discord doit pouvoir télécharger l'image sans
authentification. Il ne contient que des ressources de marque, aucun code.
